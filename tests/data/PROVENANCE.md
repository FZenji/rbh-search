# Test fixture provenance

Every binary fixture in this directory must be listed here before it is committed.
Fixtures must be under 2 MB (enforced by `pre-commit`) and derived from public archival
data. See [ADR-0010](../../docs/adr/0010-rbh1-regression-test.md).

Required per fixture: file name, source archive URI, proposal ID, instrument, filter,
the cutout region, and the command used to produce it.

## Notes on the RBH-1 fixture

- **Why that centre.** It is the midpoint of the feature's full extent, not the published
  coordinate. The published coordinate marks the host galaxy at one *end* of the wake, so
  centring on it would have put the feature entirely in one half of the cutout.
- **Why those files.** The Hubble Advanced Products single-visit mosaics for this visit are
  not resolvable in the cloud; these standard association products are. See the amendment
  in [ADR-0003](../../docs/adr/0003-search-plane-drizzled-mosaics.md).
- **Compression.** RICE with `quantize_level=16`. Largest pixel change measured at 1.7% of
  the noise, against a 3.9x size reduction that brings the file inside the 2 MB commit
  limit.
- **Contents.** Four extensions: science and weight arrays for each filter, plus the WCS
  and AB zero points (F606W 26.485, F814W 25.933) derived from `PHOTFLAM`/`PHOTPLAM`.
- **Regenerating.** `uv run rbh fetch-fixture` reproduces it from the pinned
  `RBH1_FIXTURE` specification. Only needed if the archive reprocesses the discovery data.
